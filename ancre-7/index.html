Ancre-7 · journal d'audit · accès restreint

Journal d'Ilya Sorel : la porte 0x4A30

Vous avez suivi la piste jusqu'au relais. Ce journal n'est pas référencé, et les Gardiens n'y viennent jamais. Il reste une porte à ouvrir.

Entrées du journal

[cycle 112] Segment 12 atteint. La porte 0x4A30 refuse mes patchs.
[cycle 113] Les Gardiens ont publié un correctif contre ma dernière méthode.
            Je change d'approche : je lis le code au lieu de le forcer.
[cycle 114] La serrure attend trois valeurs, en décimal, dans l'ordre.
            Elle les calcule à partir de trois registres ternaires.
[cycle 115] Ancre-7 me demande de laisser la solution à qui viendra après moi.
            Voilà : à toi de jouer.

Les registres de la porte

Rappel : en ternaire équilibré, chaque trit vaut −1, 0 ou +1, multiplié par 9, 3 puis 1 en partant de la gauche. NEG inverse chaque trit.

RegistreOpérationValeur attendue

R1NEG(−0+)sa valeur décimale
R2++−sa valeur décimale

Injecter le code

ACCÈS ACCORDÉ

La porte 0x4A30 s'ouvre. Au fond du sas, un registre clignote :

VSP-7TRIT-4A30

Ce code de bêta est fictif : il n'ouvre aucun accès, nulle part. Il prouve seulement que vous avez résolu le jeu de piste. Montrez-le avec le mot-dièse #vesperprotocol, puis essayez la mini-démo ou la démo de Vesper Protocol.
