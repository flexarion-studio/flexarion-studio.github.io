Description courte (à reprendre telle quelle)

Flexarion est un studio indépendant de jeux vidéo basé à Aix-en-Provence. Il développe Vesper Protocol, un jeu de hard science-fiction dans lequel le joueur explore et pirate les systèmes embarqués d'une mégastructure alien.
