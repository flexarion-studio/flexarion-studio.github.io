# Flexarion — site officiel

Code source du site **[flexarion-studio.github.io](https://flexarion-studio.github.io/)**, publié avec GitHub Pages (HTML/CSS statique, sans framework).


**Flexarion** est un studio indépendant de jeux vidéo de science-fiction, basé à Aix-en-Provence, créateur de **[Vesper Protocol](https://flexarion-studio.github.io/vesper-protocol/)** : un jeu de hacking en hard SF où l'on ne tire pas sur les aliens, on pirate leur code.

🌐 **Site officiel : [flexarion-studio.github.io](https://flexarion-studio.github.io/)**

## Vesper Protocol en bref

2231. Autour de Tau-Héliade, une naine rouge mourante, tourne la Vesper : un anneau alien de 400 km. Ilya Sorel, auditrice de systèmes critiques, y descend sans arme, avec un débogueur. Les Gardiens qui entretiennent l'anneau ont des failles, mais ils apprennent et corrigent celles que vous exploitez trop souvent. Il faut lire leur firmware en logique ternaire et le réécrire.

PC Windows et Linux, accès anticipé prévu en 2027. → [Fiche du jeu](https://flexarion-studio.github.io/vesper-protocol/) · [Codex de l'univers](https://flexarion-studio.github.io/codex/)
